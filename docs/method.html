01

Daily pipeline

From metadata to a readable brief.

GitHub Actions is scheduled at 07:00 JST, with a 07:20 fallback for incomplete primary runs. Actual start times may be delayed. The additional flagship spotlight has an independent once-per-day selection guard.

  1. Retrieve

    Request metadata and abstracts from Europe PMC, Crossref, and optionally arXiv.

  2. Normalize

    Convert source-specific records into one shared Paper structure.

  3. Unify

    Merge records connected by DOI, source identifier, or normalized title.

  4. Refresh

    Improve indexed records when a source later provides richer metadata or a longer abstract.

  5. Screen

    Require PopPK or pharmacometrics, AI or machine learning, and methodological evidence.

  6. Select

    Report new papers; otherwise choose one unreported, abstract-bearing paper from 2020 onward.

  7. Interpret

    Create four concise fields from the available abstract only.

  8. Publish

    Update Markdown, GitHub Issues, the canonical JSON catalog, and GitHub Pages.

02

Relevance score

A bounded measure of scope alignment.

The score ranges from 0 to 100. It ranks eligible primary-library papers by explicit alignment with this monitor. It does not assess study quality, validity, novelty, risk of bias, or clinical usefulness.

20 points in the title and 10 in the abstract.

20 points in the title and 10 in the abstract.

Method evidence0–30

20 points in the title and 10 in the abstract.

A paper must pass the three-part eligibility gate before scoring. Repeated synonyms do not add points; each component records whether evidence is present in the title or abstract. The broader flagship spotlight below does not use this score.
03

Evidence boundary

Interpretation stops at the abstract.

Titles support discovery and scoring, but not the four interpretive statements. The program does not download PDFs, visit publisher full text, or inspect supplementary material.

01

Prior limitation

What gap or problem does the abstract identify?

02

Contribution

What method, framework, algorithm, or comparison does it describe?

03

New capability

What analysis or decision becomes possible according to the abstract?

04

Significance

Why might it matter for PopPK, pharmacometrics, or model-informed dosing?

With an OpenAI API key, the abstract may be paraphrased into these four fields. Without one, the fallback extracts supporting sentences directly. Unsupported fields are reported as not stated.

04

Source policy

Core indexes, optional preprints.

Europe PMCCore source

Biomedical metadata and available abstracts. A failure is reported; the run can continue if another required source succeeds.

CrossrefCore source

Publisher-registered articles and posted content. A failure is reported; the run can continue if another required source succeeds.

arXivOptional source

Queried at most once per JST day. Rate-limit and timeout errors are logged internally but omitted from user-facing reports.

05

Program structure

Small modules, explicit responsibilities.

core.py

Data models, validation, normalization, de-duplication, scoring, JSON I/O, and HTTP requests.

sources.py

Clients for Europe PMC, Crossref, and arXiv.

insights.py

Abstract-only interpretation with optional AI paraphrasing and an extractive fallback.

literature_monitor.py

Retrieval orchestration, catalog refresh, selection, notifications, and state updates.

reporting.py

Canonical article records, Markdown reports, and GitHub Issues.

site_generator.py

Validates and transforms the primary catalog into data consumed by GitHub Pages.

data/articles.json

The canonical primary catalog used to build the site.

state/seen.json

Shared seen identifiers, primary source health, and primary run dates.

flagship.py

Exact journal checks, research-profile matching, the additional daily selection, and its separate report and catalog.

flagship_config.json

Research topics, contextual constraints, priorities, date windows, and API result limits.

06

Known limits

A reading queue, not a systematic review.

  • Keyword screening can produce false positives and false negatives.
  • Abstracts may omit important methods, validation details, and limitations.
  • The relevance score measures scope alignment, not study quality.
  • Source metadata may differ in dates, abstracts, and publication types.
  • API result limits and indexing delays prevent guaranteed completeness.
  • The archive fallback is a ranked convenience sample, not an exhaustive search.
07

Visual system

Clarity first.

The interface uses system typography, generous spacing, restrained color, layered translucent materials, and optional motion. The visual hierarchy keeps controls near the content they modify and gives each paper enough space to be read without visual noise.

01

Readable

Large type, strong contrast, and clear section hierarchy support fast scanning.

02

Responsive

Layouts collapse cleanly without horizontal scrolling, and controls remain touch-friendly.

03

Layered

Translucency and soft separation indicate hierarchy without obscuring content.

04

Calm

Motion is slow, optional, and automatically respects reduced-motion preferences.

All interface graphics are original HTML, CSS, and SVG. No third-party product imagery or brand assets are embedded.

08

Science · Cell · Nature

One additional research connection.

The Research Spotlight selects one paper across all three flagship journals per JST day, in addition to the primary monitor. It runs even when the primary search already selected new or archive papers. It is not a requirement that every spotlight combine PopPK and AI.

ScienceFlagship only

Print ISSN 0036-8075; electronic ISSN 1095-9203.

CellFlagship only

Print ISSN 0092-8674; electronic ISSN 1097-4172.

NatureFlagship only

Print ISSN 0028-0836; electronic ISSN 1476-4687.

Both the journal title and an approved ISSN must match. Sister journals, reviews, news, editorials, corrections, and records without an abstract or research-article metadata are excluded. Europe PMC supplies indexed metadata and abstracts; no publisher full text is requested.

01

Research profile

Federated and privacy-preserving analysis; mechanistic inference; lymphatic and vascular biology; endothelial signaling; sequential treatment decisions; virtual cells and perturbations.

02

Evidence of a connection

At least one topic must match the abstract. Broad terms such as mTOR require vascular or endothelial context. A generic AI mention or a journal's reputation is insufficient.

03

Recency and ranking

Search the last 30 publication days first. If no unreported match is available, use the 2020+ archive. Topic priority, up to three matched topics, publication date, and stable ID determine the order.

04

No invented findings

The same four abstract-only findings are reported. Potential uses in the research profile appear separately and are explicitly suggestions, not demonstrated applications or clinical recommendations.

Topic priorities are configurable: federated analysis 60; lymphatic or vascular biology 55; mechanistic inference and endothelial signaling 50; treatment decisions 45; virtual-cell methods 40. These are reading preferences, not quality scores. The primary library's 0–100 relevance score is not assigned to spotlights.

This separate section maintains its own daily history in data/flagship.json, a report in reports/flagship/, and a GitHub Issue. Its validated Pages data is written to docs/flagship.json and published through the existing monitor-to-Pages deployment chain. Shared identifiers prevent a paper already introduced in either stream from being introduced again.

Searches retrieve at most three pages of 200 records per pass. Archive results are cached for up to seven days, with earlier refresh when the usable pool is exhausted. Cached abstracts may be used during an outage. If no eligible paper is available, the monitor reports that condition rather than substituting an unrelated paper. The original literature monitor and its catalog are retained.
