Folio II · Construction and measure

How the monitor works

The program separates observation, selection, interpretation, and publication. Full text is never fetched. Interpretive statements are generated from the available abstract only.

Scope

Discovery: title + abstract
Interpretation: abstract only
Output: Issue, Markdown, JSON, HTML

01

Daily pipeline

GitHub Actions starts the monitor at 07:00 JST. A 07:20 fallback runs only when the first run did not complete successfully.

  1. Observe

    Retrieve bibliographic metadata and abstracts from Europe PMC, Crossref, and optionally arXiv.

  2. Normalize

    Convert source-specific records into one Paper structure and normalize DOI and title text.

  3. Unify

    Merge duplicate records that share a DOI, source identifier, or normalized title.

  4. Screen

    Require PopPK/pharmacometrics, AI/ML, and methodological evidence.

  5. Select

    Report new eligible papers; when none are found, select one unreported paper published since 2020.

  6. Interpret

    Summarize the prior limitation, contribution, new capability, and significance from the abstract only.

  7. Publish

    Write a Markdown report, create a GitHub Issue, update the JSON catalog, and rebuild this site.

02

Relevance score

The score is a transparent 0–100 measure of topical and methodological alignment. It does not evaluate scientific quality, risk of bias, validity, novelty, or clinical usefulness.

PopPK evidence 0–30

20 points when a PopPK/pharmacometrics term occurs in the title, plus 10 when it occurs in the abstract.

AI evidence 0–30

20 points for an AI/ML term in the title, plus 10 for evidence in the abstract.

Method evidence 0–30

20 points for a method term in the title, plus 10 in the abstract. Inherently methodological AI terms also count.

Intersection bonus 0–10

10 points when both PopPK/pharmacometrics and AI/ML are explicit in the title.

R = PK + AI + Method + Intersection

High70–100

Medium40–69

Low0–39

A paper must first pass the three eligibility conditions. The score then ranks eligible papers. Repeated synonyms do not add extra points; each component is based on presence or absence.

03

Abstract-only interpretation

The title may help discovery and scoring, but it is not used as evidence for the four interpretive statements. The program does not download PDFs, visit publisher full text, or inspect supplementary material.

Prior limitation

What problem or gap does the abstract identify?

Contribution

What method, framework, algorithm, or comparison does the abstract describe?

New capability

What analysis or decision becomes possible according to the abstract?

Significance

Why might the method matter for PopPK, pharmacometrics, or model-informed dosing?

When no abstract is available, the program states that the evidence is unavailable instead of inferring a conclusion from the title.

04

Source policy

Source Role Failure behavior
Europe PMC Primary biomedical metadata and abstracts Displayed as a warning; required for normal operation
Crossref Publisher-registered articles and posted content Displayed as a warning; required for normal operation
arXiv Optional preprint supplement HTTP 429 and timeout errors are logged internally but omitted from reports

05

Program structure

core.py

Data models, text normalization, de-duplication, scoring, JSON I/O, and HTTP requests.

sources.py

Europe PMC, Crossref, and arXiv clients.

insights.py

Abstract-only interpretation, with an optional AI paraphrase and a deterministic fallback.

literature_monitor.py

Source orchestration, recent and archive selection, notifications, and state updates.

reporting.py

Canonical article records, Markdown reports, and GitHub Issues.

site_generator.py

Transforms the structured catalog into the JSON used by GitHub Pages.

data/articles.json

The canonical structured catalog. The site no longer parses its own Markdown reports.

state/seen.json

Seen identifiers, source health, and run dates used to prevent duplicate alerts.

06

Known limitations

  • Keyword screening can produce false positives and false negatives.
  • Abstracts may omit important methods, validation details, and limitations.
  • The relevance score measures alignment with the search scope, not study quality.
  • Crossref and Europe PMC metadata may differ in dates, abstracts, and publication types.
  • The archive fallback is a ranked convenience sample, not a systematic review.

07

Visual language

The interface is an original interpretation of Leonardo da Vinci's working notebooks rather than a reproduction of any artwork. Warm paper, brown ink, red-chalk accents, measured grids, and geometric studies express observation, proportion, and the union of visual and scientific reasoning.

Design references: Royal Collection Trust — anatomy, proportion, and measurement; The Met — compositional and perspectival geometry.
